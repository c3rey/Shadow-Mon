## GamePoint

A point on the screen that belongs to a [Path](path.md) and has a previous and next reference; extends java.awt.Point

| Variable |   Type    | Description                                 |
|:--------:|:---------:|---------------------------------------------|
|   prev   | GamePoint | The GamePoint previous to this in a Path.   |
|   next   | GamePoint | The GamePoint next to this point in a Path. |
